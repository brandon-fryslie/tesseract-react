1. Added `makeObservable` to the import from 'mobx'
2. Added `makeObservable(this);` as the first line in the constructor (after super() if present)

Example transformation:
```javascript
// Before
import { observable } from 'mobx';
class Foo {
  @observable bar;
  constructor() {
    this.bar = 1;
  }
}

// After
import { observable, makeObservable } from 'mobx';
class Foo {
  @observable bar;
  constructor() {
    makeObservable(this);
    this.bar = 1;
  }
}
```
