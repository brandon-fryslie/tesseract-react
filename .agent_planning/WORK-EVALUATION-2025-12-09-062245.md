## What Needs to Change

### Priority 1: Fix CSS Minifier (CRITICAL)

**File:** `/Users/bmf/code/brandon-fryslie_tesseract-react/webpack/webpack.prod.js`
**Line:** 23
**Problem:** `CssMinimizerPlugin` stripping media queries

**Solution:** Configure CssMinimizerPlugin to preserve media queries:

```javascript
new CssMinimizerPlugin({
  minimizerOptions: {
    preset: [
      'default',
      {
        discardComments: { removeAll: true },
        // Preserve media queries!
        minifySelectors: true,
        mergeLonghand: true,
        mergeRules: true,
      },
    ],
  },
}),
```

**Alternative:** Update to latest css-minimizer-webpack-plugin version (may have bug fix)
