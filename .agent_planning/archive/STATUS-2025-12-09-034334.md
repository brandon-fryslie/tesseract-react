**Locations**:

- `src/components/PlaylistsList.tsx(40,17)`
- `src/components/ScenesList.tsx(53,23)`

**Issue**: React-Bootstrap expects `boolean | undefined` but code provides `boolean | null | undefined`

**Pattern**:
